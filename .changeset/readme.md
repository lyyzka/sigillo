# Changesets

Pending release notes for the CLI (`sigillo`) and the website (`sigillo-app`).

`sigillo-app` is private. It still gets a CHANGELOG. Always include it when the website or API changes.

## What to put here

- One kebab-case `.md` file per logical change
- `patch` for fixes, `minor` for new features
- Present tense, focused on what users see
- `Fixes #123` on its own line when the change closes an issue

## What not to put here

- Do not skip `sigillo-app` because it is private
- Do not edit `CHANGELOG.md` directly
- Do not run the interactive changeset CLI
